# Album Display

A Raspberry Pi-powered LED matrix display that shows album art from Spotify or WiiM devices.

## Features
- 64x64 LED matrix display
- WiFi configuration via web interface
- Spotify integration
- WiiM device support
- Automatic reconnection
- Easy setup with WiFi Access Point

## Hardware Required
- Raspberry Pi 4B
- Adafruit 64x64 RGB LED Matrix Bonnet
- 64x64 RGB LED Matrix Panel
- 5V 4A+ Power Supply
